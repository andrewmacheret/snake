# snake

[![License](https://img.shields.io/badge/license-MIT-lightgray.svg)](https://github.com/andrewmacheret/snake/blob/master/LICENSE.md)

Snake for Node.js using [blessed](https://www.npmjs.com/package/blessed).

Prereqs:
 * [Node.js](https://nodejs.org)

To run:

  ```bash
  npm install

  node terminal-snake.js
  ```
